# Cool Desktop

Windows 桌面工作台，用於管理 Cool English 帳號、課程連結及學習時間。桌面 UI 以 Electron、React、TypeScript、Playwright 和 xterm.js 建置；內嵌終端使用 node-pty 與系統已安裝的 shell。

## 功能

- 有頭與無頭登入都會先從 Cool English 登入頁進入 Google 登入，使用與 `cool -l` 相同的 Google OAuth provider（`id=2`），依序處理帳號與密碼；不會點擊 Facebook 或其他 OAuth provider。Google 地區登入網域（包括 `accounts.google.com.tw`）和跨頁重新導向都會持續監看；按下帳號／密碼頁的送出後不等待導航完成，並在重新導向後重新檢查所有作用中的頁面，避免因 Google 關閉或替換舊頁而漏掉返回 Cool English 的登入狀態。並以受保護的 Moodle 首頁確認登入狀態及可用的 `MoodleSession` cookie 後才保存。帳密與 cookie 分別以 Windows 系統加密保存。有頭登入會讓瀏覽器保持開啟，供使用者完成 MFA、安全金鑰、通行密鑰、CAPTCHA 或其他手動步驟；無頭登入若遇到同類互動驗證，會比照 CLI 保留瀏覽器狀態並自動切換為可見瀏覽器，提示使用者手動完成，再繼續確認登入；不會繞過網站安全檢查或假報成功。
- 登入完成判斷沿用 `cool.py`：從 Playwright browser context 擷取 Cool English 網域 cookie，拒絕無效/過期/非目標網域的 `MoodleSession`，並優先檢查實際瀏覽器已渲染的 Cool English 頁面，再以 Moodle 首頁驗證補充確認（含首頁重新導向及帳號資料補填頁），避免只讀取未執行 JavaScript 的 HTTP 回應而漏認已登入頁面。抵達 Cool English 時會在 UI 提示正在驗證；監看同時輪詢頁面與 cookie，避免導航事件剛好發生在等待切換時而漏掉；支援 `www.coolenglish.edu.tw` 與 `coolenglish.edu.tw`。加密 cookie 與帳號狀態持久化成功後才發出登入成功通知，再關閉瀏覽器；登入等待有明確上限，逾時會回報最近驗證診斷，不會假報成功或無限卡住。
- 「網路紀錄」的「正在運行」清單會在每筆執行中的 Playwright 工作階段旁提供「終止」操作。確認後只關閉該筆工作階段所屬的瀏覽器，狀態更新為「已停止」並停止收集事件；取消確認不會影響執行中的工作。登入頁不提供終止按鈕。
- 可檢查 cookie 狀態與到期時間，並使用已儲存的加密密碼重新登入。狀態刷新會用保存的 MoodleSession 請求實際學習時數頁：成功取得時數表格才標為有效，明確被導向登入頁才標為過期；暫時性錯誤或無法辨識的頁面標為待檢查，不會只根據本機 cookie 到期時間誤判。
- 桌面與內嵌終端帳號清單會雙向同步：終端新增或更新帳號會匯入桌面，桌面新增、重新登入或改名的帳號也會同步到 CLI，桌面刪除帳號時會移除 CLI 對應紀錄。已開啟的終端會在下一次查詢帳號時重新讀取清單；目前已顯示的互動選單不會中途改寫，請先返回再重新開啟。桌面端 Cookie 以 Windows 系統加密保存；為讓 CLI 可直接使用桌面帳號，CLI 的 `cookies` 目錄會保存該帳號的明文 Netscape Cookie 檔，請妥善保護該資料夾。CLI 已保存的密碼仍會匯入桌面並立即以 Windows 系統加密重新保存；桌面只提供「已保存密碼」狀態，不會把明文密碼送到 renderer。若舊終端密碼無法在本機解密，會明確提示使用桌面重新登入一次，不會保存或顯示錯誤密碼。
- `cool -t` 與桌面「學習報表」共用相同方式：使用所選帳號已保存的 Cookie 直接取得學習時數 HTML 並解析表格，不啟動瀏覽器或 headless Chromium。桌面會將結果呈現在報表頁，並在網路紀錄中標示為「直接請求」；若網站要求重新登入或 HTML 結構有變，會清楚回報而不顯示假資料。
- 課程網址可依分類整理，也可設定別名；同一別名可選擇一次開啟全部網址，且該批次會記為單一 Playwright 工作階段。預設別名會跟隨分類；更改分類時同步更新仍沿用舊分類名稱的預設別名，因此課程不會繼續留在「未分類」群組。既有資料若分類已更新、別名仍是「未分類」，載入時會自動校正該預設別名；自訂別名則保留。桌面與 CLI 透過 `urls.txt` 的 `# group:`（連結別名）及 `# category:`（分類）標記雙向即時同步；桌面監看終端清單變動，終端新增、改名、分類調整及刪除都會即時反映到桌面，終端刪除的連結也會從桌面清單移除。舊版只有連結組標記或未分類的清單仍可匯入，且不會覆蓋桌面既有分類與別名。
- 「網路紀錄」分為進行中與歷史，並可用「有頭紀錄／無頭紀錄／直接請求」切換，避免不同執行方式混在同一列表。各模式旁的垃圾桶可進入多選刪除，也能全選該模式目前列出的歷史紀錄；進行中的工作階段不可刪除。記錄實際 Chromium request、response 與失敗事件，以及不啟動瀏覽器的報表直接請求，依工作階段分組；工作階段以分隔線清楚區分，選擇「看數據」會切換至該工作階段專屬詳情，並可在「排版檢視」與單一捲動框中的原始 JSONL 事件及本文分塊資料間切換，歷史詳情可匯出為包含本文的單一工作階段 JSON。設定中的「記錄原始 Request／Response 本文」預設關閉；關閉時完全不保存 request／response 本文，以減少大量本文造成的記憶體及效能負擔，只保存網路事件與已遮蔽的 URL／Headers。若進一步將紀錄方式設為「停用」，開啟課程仍會執行，畫面會切換到「網路紀錄 > 正在運行」及相符的有頭／無頭模式，逐筆課程標題與 `[ OK ]`／`[ WARN ]` 狀態直接顯示在紀錄列表中，並標示為即時進度、不保存為網路事件；不會另外開啟終端面板。開啟原始本文擷取後，新的 Playwright 工作階段及報表直接請求會將可取得的本文以原始位元組、不遮蔽、不截斷、不加密的方式寫入本機附件；設定不會追溯影響既有紀錄。原始模式下匯出檔的本文以 Base64 無損承載，原始 JSONL 以 Base64 分塊呈現；本文閱讀與匯出採串流處理。未加密本文可能含密碼、Cookie、權杖及個人資料，請自行保護本機資料。Chromium CDP 不提供 multipart/form-data 上傳中的檔案位元組，此類 request body 會明確標示無法擷取，不會把不完整內容當作完整本文。紀錄不設工作階段或事件筆數上限；設定中的「網路紀錄」類別可選擇永久保留、停用新紀錄，或於工作階段結束後按指定分鐘／小時／天數自動刪除整筆舊紀錄。
- 在課程連結選擇無頭開啟時，瀏覽器會在背景持續執行，已開啟的頁面與網路工作階段不會在載入後自行關閉；可在「網路紀錄 > 正在運行」明確終止該工作階段。這與「無頭登入」完成後關閉登入瀏覽器的行為不同。
- 無頭登入遇到 Cool English 登入頁載入 Google reCAPTCHA、MFA 或其他驗證時，會比照 CLI 保留登入狀態切換至有頭瀏覽器，由使用者完成驗證；不會嘗試自動解題或繞過。瀏覽器關閉後才發生的 response 本文讀取錯誤不會當成伺服器回應內容記錄。
- 標題列品牌標誌使用與應用程式一致的圖示圖片，固定圖示尺寸不隨介面字體大小變動。工作台問候語由內嵌的多句文案按日期輪換。
- 內嵌終端使用 xterm.js 與 node-pty，只提供裝置上可用的 PowerShell、命令提示字元及 Visual Studio 開發者 shell。工作臺啟動時不自動建立終端；點標題列的終端按鈕開啟空白終端區，再按「＋」選擇系統終端。每個新終端都從目前找到的 Cool 專案目錄直接執行 `python cool.py`，讓原腳本執行 Python 套件檢查後進入 `cool>`；啟動輸出會在 xterm 就緒後才送出，避免初始提示或使用者輸入遺失。拖曳分割比例時會逐影格同步應用程式版面、xterm 與 PTY 尺寸；拖曳期間輸入會暫存，待最終終端尺寸套用後才送入，避免互動提示因尺寸和輸入不同步而錯位。視窗大小變更或應用程式重新取得焦點時也會同步尺寸。CMD 透過互動提示送入啟動命令，以相容含括號或空格的專案路徑。安裝版會附帶該 CLI 原始碼，並使用裝置上安裝的 Python。任一終端輸入 `/exit` 關閉整個工作臺。支援 ANSI/VT、選取、右鍵選單與 Ctrl+Shift+C/V 複製貼上。隱藏終端不會結束 shell。
- CLI 以 `cool -u` 管理新增／刪除連結：輸入連結編號只刪該連結，輸入分類名稱或 `分類:<名稱>` 可確認後刪除該分類內全部連結；`cool -g` 選擇並執行連結組，可輸入 `a|b` 同時開啟多組，`-s` 可切換成有頭瀏覽器。終端會顯示並同步桌面設定的分類與連結別名。新增連結留白群組名稱時會嘗試使用有效 Cool English Cookie 讀取課程標題，將「歡樂電影城」歸入「影片」、其他課程歸入「學習」；讀取失敗或 Cookie 無效時改用連結中第一個數字命名，重名自動加上 `(1)` 等序號。`cool -n` 可重新命名帳號或連結組，`cool -t` 在多帳號時會提供帳號選單；`&&` 可在互動提示中依序執行多個指令。帳號移除請使用桌面帳號頁面。
- 設定首頁將「外觀與配色」、「終端」、「工作區」、「學習報表」、「CLI 報表配色」及「資料與隱私」分成獨立類別。分類順序可在首頁雙擊任一分類卡片進入排序模式，拖曳卡片調整位置後按「完成排序」；排列保存於設定檔，舊設定會自動補齊新分類。設定首頁也顯示 Cool Desktop 1.0.0 簡介、早期測試者、作者及問題討論群組聯絡方式。外觀內建 24 組高辨識暖色、冷色、自然與鮮明風格，涵蓋深色與淺色介面；每組有不同色調的介面背景及卡片色，不只是黑白切換，並預覽介面、強調色與終端配色。深色風格的背景與面板刻意拉開亮度和色相，確保差異在實際介面中也清楚可見。套用時同步更新介面主題與終端配色，也可再自訂。桌面「終端」設定的游標、文字及背景色會與 `cool -c` 共用 `colors.json`；「CLI 報表配色」獨立顯示 CLI 報表示意預覽，並提供標題外框、標題文字、表頭、當月列、未達標列、網址列及分隔線七種顏色的樣式選擇與自訂 HEX 色盤。包含 `REVERSE`、紅底白字及 256 色在內的設定會保留 CLI 格式；終端三色與報表七色都由桌面和 `cool -c` 雙向即時同步，並保留 `colors.json` 其他欄位。CLI 透過終端 OSC 色彩序列套用共享終端配色。介面字體與終端字體有獨立大小滑桿，分別即時調整文字與 xterm 字體，不縮放視窗或版面，並 debounce 持久保存。字體家族供介面使用，終端維持等寬字體。「反轉介面文字顏色」只切換文字前景色，不改背景，也不影響終端，並維持主題對比。介面自訂文字色會檢查對比度；不足時保留可讀的主題文字色。課程有頭／無頭操作及網路紀錄模式以高對比顏色和文字標籤區分。預設門檻沿用舊版的 12 小時。
- 側邊選單上方以可點擊的應用程式圖示取代 `WORKSPACE` 標題。設定的「工作區」類別可選擇點擊圖示切換顯示／隱藏，或將滑鼠移至視窗左側顯示並在移出側邊選單右緣時隱藏；舊設定會沿用預設的點擊模式。
- 在任一內嵌終端輸入 `/exit` 會關閉整個工作臺。

## 開發與啟動

需求：Windows、Node.js 22 或更新的 LTS 版本，以及 npm。`cool.py` 的環境檢查只檢查 CLI 使用的模組；舊版獨立 PyQt GUI 的 `PyQt6`、`pyte` 與 `pywinpty` 不屬於 CLI 必要依賴，不會因這些模組未安裝而要求安裝。

日常使用請直接雙擊安裝後的 **cool** 應用程式捷徑（或 `desktop\dist\win-unpacked\cool.exe`）；Electron 桌面應用程式不再透過 `cool.py` 啟動。開發時在 `desktop` 目錄執行 `npm run dev`。按應用程式中的終端按鈕，再按「＋」選擇系統終端；終端會在含有 `cool.py` 的專案目錄執行 `python cool.py`。CLI 會自行檢查所需 Python 套件，因此使用內嵌 CLI 終端需要安裝 Python。

```powershell
cd desktop
npm ci
npm test
npm run dev
```

根目錄的 `run-desktop.bat` 是開發版啟動捷徑；日常使用安裝程式建立的應用程式捷徑直接開啟。

## 建置 Windows 安裝程式

```powershell
cd desktop
npm ci
npm run build:win
```

或在根目錄執行 `build.bat`。安裝檔輸出至 `desktop\dist`；安裝包會附上供內嵌終端使用的 CLI 原始碼，但需要裝置上安裝 Python 及 CLI 所需套件。桌面 UI 本身由 Electron 直接啟動，不透過 `cool.py`。Microsoft Edge 可供 Playwright 優先使用；若 Edge 不可用，需另外安裝 Playwright Chromium。

## 舊版資料

首次啟動時會嘗試從舊專案目錄匯入 `accounts.json`、帳號 cookie 與 `urls.txt`。匯入的 cookie 會升級為系統加密格式；新資料存放於 Electron 的使用者資料目錄，帳密與 cookie 分開保存。請保留舊專案資料夾及備份，直到確認帳號和課程資料都已成功移轉；舊版未保存的密碼不會被移轉。

Python CLI 保留為內嵌終端的 `cool>` 介面；它與 Electron 桌面程式分開啟動，`python cool.py` 不會開啟桌面視窗。

## Git 提交與個人資料

提交原始碼時請勿加入帳號、Cookie、密碼或本機課程／配色設定。根目錄 `.gitignore` 會排除 `accounts.json`、`cookies/`、`.cool_passwd`、`colors.json`、`urls.txt`、環境變數與金鑰檔，以及 Python 快取、Node.js 依賴與 Electron 建置輸出。乾淨複本可用 `python cool.py` 啟動 CLI；桌面程式則在 `desktop` 執行 `npm ci` 後使用 `npm run dev`，或透過 `build.bat` 建置 Windows 安裝程式。
